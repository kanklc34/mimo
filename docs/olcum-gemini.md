# Gemini talimat değerlendirmesi

Bu rapor henüz üretilmedi. Sayısal sonuçlar yalnızca `scripts/eval_gemini.py` gerçek Gemini koşusunu tamamladığında bu dosyaya yazılır.

Çalıştırma komutu:

```powershell
C:\Users\KAAN\miniconda3\envs\mimo\python.exe scripts/eval_gemini.py
```

Koşu tamamlandığında betik bu şablonu model kimliği, doğru oranı, kısıt tipi ve hata türü dökümleri, hatalı cümle/ham yanıt örnekleri ve vaka başına çağrı sayılarıyla değiştirecektir. API anahtarı rapora yazılmaz.
